# Showcase: `web-scraper` on lovii.ru

> Демонстрация работы скилла на **реальном** проекте — публичном лендинге
> **lovii.ru** (White Paper v1.22, ООО «Аксиома», June 2026).

## 1. Вход (Input)

| Что | Где |
|---|---|
| Проект (сайт) | https://lovii.ru/ (публичная страница White Paper) |
| Что скрапим | основной контент страницы (`body`) → Markdown |
| Задача для скилла | Получить читаемый Markdown-сводку White Paper: разделы, ключевые метрики, контакты, таблица архитектуры |

*Почему именно эти данные:* лендинг с большим объёмом связного текста, таблицами,
якорными ссылками и встроенными цифрами — типичный кейс «собрать суть проекта
с публичной страницы».

## 2. Запуск (Run)

```bash
# Из репозитория agent-skills:
python3 skills/web-scraper/scripts/scrape.py --url "https://lovii.ru/" --selector "body" --delay 0.5
```

Скилл уважает guardrails: проверяет `robots.txt` (политика разрешена), задержка 0.5 c,
честный User-Agent.

Полный вывод (Markdown, ~15 КБ) — затребуется отдельной командой с сохранением в
файл (`> docs/showcase/web-scraper-lovii.md`).

## 4. Интерпретация (Interpretation)

- Результат — полный Markdown-слепок White Paper: все 8 разделов, таблица
  архитектуры (4 компонента), контакты и якорные ссылки.
- **Полезно владельцу `lovii_demo`**: упакованный текст страницы можно напрямую
  скрейпить в аналитику (считамость ключевых метрик — GMV, комиссия, Retention),
  в репозиторий документов, либо для сверки фактического содержания сайта и
  `docs/*.md` в репозитории.
- **Ограничение**: скринит только статику страницы (White Paper внутри HTML),
  не рендерит JS-взаимодействия; для SPA-экранов (`index.html`/`index.js`)
  нужен headless-браузер (Playwright) — вне скоупа этого скилла.
