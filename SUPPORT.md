# Support

This project is a collection of autonomous skill instructions for AI agents. It
has no "support desk" — help comes from the community and from the maintainers.

## Where to get help

| Need | Where |
|------|-------|
| **Questions** | [Discussions](https://github.com/bestdeejay-design/agent-skills/discussions) |
| **Bug reports** | [Issues → Bug report](https://github.com/bestdeejay-design/agent-skills/issues/new?template=bug_report.yml) |
| **Feature requests** | [Issues → Feature request](https://github.com/bestdeejay-design/agent-skills/issues/new?template=feature_request.yml) |
| **Security vulnerabilities** | [SECURITY.md](SECURITY.md) — do **not** open a public issue |

## Before asking

1. Read the skill's `SKILL.md` and `skill.json` (requirements, triggers, files).
2. Check [index.json](index.json) for the correct skill name/category.
3. Search existing issues and discussions for a prior answer.

## Support levels

- **Official skills** (in `skills/`): supported by maintainers.
- **Custom/local skills**: best effort only.
- **Examples** (`examples/`): reference material, may not be maintained.

There is no SLA. Maintainers typically respond within a few days.
