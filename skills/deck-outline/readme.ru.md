# deck-outline (RU)

> Русское описание скилла. Сам скилл (`SKILL.md`, `skill.json`) — на английском.

**Назначение:** построение структуры презентации из темы/промпта: параметры
(число слайдов, язык, тон, объём), контент-рулы (один слайд = одна мысль, без
жирного/курсива, без URL, без эмодзи — только SVG-иконки), маппинг контента в
лейауты (title/table/chart/comparison/process/metrics…) и автовыбор лейаута.
Выход: `outline.md` + JSON-спека, которую потребляют `deck-html` (слайды) и
`deck-pptx` (PowerPoint).

**Когда применять:** просят «план презентации», «структуру слайдов», «раскадровку»;
нужно сначала собрать структуру, а потом уже слайды/pptx.

**Не применять:** для сборки самих слайдов — это `deck-html`; для сборки .pptx —
это `deck-pptx`.
