# frontend-design-taste (RU)

> Русское описание скилла. Сам скилл (`SKILL.md`, `skill.json`) — на английском.

**Назначение:** задать сайту **осмысленное дизайн-направление**, которое не читается
как шаблонный AI. Это «искусство»: палитра, типографика, лейаут и одна сигнатура.
Метод основан на официальном скилле Anthropic (`frontend-design`), адаптирован под
opencode/Sisyphus, с рабочим примером (ishotgirls).

**Когда применять:** просят «сделай красиво», «не как у всех», «дизайн-направление»,
«переделай со вкусом»; странице нужна эстетика до написания кода; текущий дизайн —
шаблонный AI.

**Что делает:**
1. Погружается в тему проекта (мир, материалы, жаргон) — отсюда берутся нешаблонные ходы.
2. Предлагает компактную токен-систему: палитра (4–6 hex), роли шрифтов
   (display/body/mono), концепт лейаута, **одна сигнатура** — запоминающийся элемент.
3. Прогоняет «гейт уникальности»: если план похож на дефолт — переделывает и объясняет, что и почему.
4. Переписывает копирайт со стороны пользователя (активный залог, конкретика).
5. Доводит до «качества-пола»: responsive, `:focus-visible`, `prefers-reduced-motion`.

**Три AI-дефолта, которых избегаем** (по методу Anthropic):
1. Кремовый фон + serif + терракота.
2. Почти-чёрный фон + кислотный зелёный/вермильон (типичный «фитнес/гамминг»).
3. Broadsheet: hairline-линии, ноль скруглений, плотные колонки.

**Композиция с другими скиллами:**
- `frontend-design-taste` — задаёт направление (искусство).
- `frontend-perfection` — проверяет и доводит результат: контраст ≥4.5:1, токены,
  Lighthouse (наука). Передаёшь ему готовое направление для аудита.
- `seo-toolkit` — SEO/Core Web Vitals (отдельный слой).

**Проверенный пример (ishotgirls):** заброшенная страница переделана по этому методу —
индиго `#161A2E` + кость `#F4F0E4` + янтарь `#FFB347`, Archivo Black вместо Lora,
hero-«табло» с цифрами, сигнатура — Instagram-грид 3×3, контраст 15:1. Кейс в `SKILL.md`.
