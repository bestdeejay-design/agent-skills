# raster-to-svg

**Конвертация PNG в чистый векторный SVG локально — без загрузок в облако, без зависимостей.**

Два движка трассировки в одном инструменте: встроенный трассер на чистом Python (контурные кривые Безье / мозаика из примитивов) и опциональный бинарь **vtracer** (высококачественная цветная трассировка, в 2–4× быстрее на фото). Всё это обёрнуто в аккуратный тёмный веб-интерфейс: drag & drop, живое превью, лупа ×4 над результатом, быстрые пресеты, прогресс-бар с оценкой времени и просмотр кода SVG.

![UI](docs/ui_v2_final.png)

## Возможности

- **Два движка**: `native` (Python stdlib, без зависимостей) и `vtracer` (если установлен); `auto` сам выбирает vtracer при наличии
- **Два режима native**: `contour` (гладкие кривые Безье, дырки) и `mosaic` (прямоугольники/круги/треугольники/ромбы)
- **Настройки vtracer в UI**: пресет (poster/photo/bw), точность цвета, фильтр пятен
- **Редактор палитры**: свотчи цветов по группам — клик перекрашивает цвет, «→» сливает два цвета в один
- **Экспорт**: DXF R12 (слои по цвету заливки, с флэттенингом), EPS, PNG (клиентский canvas, масштаб ×1–×4)
- **Пакетная обработка**: конвертация нескольких PNG текущими настройками, все SVG скачиваются одним `.zip`
- **Умный UI**: настройки, неприменимые к выбранному движку, автоматически скрываются; 12 быстрых пресетов (плоский стиль, минимал, лайн-арт, иконка, логотип, фото-плоский, фото, дуотон, винтаж, чб, мозаика-постер, мозаика-круги) с меткой «ручные настройки» при ручном изменении; подготовка фото (сглаживание + ступени цвета) до трассировки; липкая колонка превью; upscale ×2/×4 для мелких исходников; JPG/WEBP принимаются (локально перекодируются в PNG)
- **Прогресс-бар** с эмпирической оценкой времени (погрешность ~10%)
- **100% локально**: файлы не покидают ваш компьютер — сервер слушает `127.0.0.1`
- **Детерминированный вывод**, SVG валидируется перед записью, JSON-отчёт (CLI), лицензия MIT

## Требования

- Python 3 (только stdlib — никаких pip-пакетов)
- Опционально: бинарь `vtracer` (`cargo install vtracer-cli --version 1.0.0-alpha.3`, исполняемый файл называется `vtracer`)

## Быстрый старт

Нужен **только Python 3** — трассер на чистой стандартной библиотеке, `pip install` не требуется. `vtracer` — опционально (см. [Сравнение движков](#сравнение-движков)).

### macOS — приложение в один клик

1. Скачайте **`R2S.app.zip`** из [последнего релиза](releases/latest)
2. Распакуйте (двойной клик), перетащите `R2S.app` на Рабочий стол или в Программы
3. Двойной клик по `R2S.app` — он запускает локальный сервер в фоне и открывает браузер

Бандл самодостаточен: `scripts/` и `web/` лежат внутри приложения, поэтому оно работает из любого места. Остановить сервер — кнопкой **⏻ Остановить сервер** в шапке веб-интерфейса.

### macOS / Linux — из исходников

```bash
git clone https://github.com/bestdeejay-design/raster-to-svg.git
cd raster-to-svg
python3 scripts/raster_to_svg_server.py --port 8642
# открыть http://127.0.0.1:8642/  (браузер откроется сам)
```

Остановка сервера — `Ctrl+C` в терминале.

### Windows — из исходников

1. Установите Python 3 с [python.org](https://www.python.org/downloads/) — при установке **обязательно отметьте «Add python.exe to PATH»**
2. Скачайте репозиторий: зелёная кнопка **Code → Download ZIP** (или `git clone`, если есть Git)
3. Двойной клик по **`scripts\start_server.bat`** — запустит сервер и откроет браузер
   (или выполните `python scripts\raster_to_svg_server.py` в терминале; остановка — `Ctrl+C`)

### CLI

```bash
# Базовая конвертация (контур, движок auto)
python3 scripts/raster_to_svg.py -i logo.png -o logo.svg

# Меньше цветов, белый фон
python3 scripts/raster_to_svg.py -i logo.png -o logo.svg --colors 4 --bg white

# Режим мозаики
python3 scripts/raster_to_svg.py -i photo.png -o photo_mosaic.svg --mode mosaic

# Явно vtracer + JSON-отчёт
python3 scripts/raster_to_svg.py -i photo.png -o out.svg --engine vtracer --json
```

## Сравнение движков

| | native | vtracer |
|---|---|---|
| Установка | встроен | опциональный бинарь |
| Режимы | contour / mosaic | spline (через пресеты) |
| Фото (1024²) | ~9 с, 8 путей | ~2 с, 2014 путей |
| Плоская графика | компактно, точно | быстро, чуть тяжелее |
| Флаги CLI | `--smooth --corner --seam --cell --shape` | `--vtracer-preset --vtracer-mode --vtracer-color-precision --vtracer-filter-speckle` |

Полный бенчмарк — в `BENCHMARK.md` (входит в дистрибутив `agent-skills`).
