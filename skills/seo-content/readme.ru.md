# seo-content (RU)

> Русское описание скилла. Сам скилл (`SKILL.md`, `skill.json`) — на английском.

**Назначение:** контентный слой SEO — качество текста (тонкий контент, дубли,
читаемость Flesch-Kincaid, сигналы E-E-A-T), ключевые слова (плотность,
каннибализация, LSI, long-tail, интенты), иерархия заголовков H1–H6, оптимизация
картинок (alt, WebP/AVIF, lazy, srcset).

**Скрипт** `scripts/seo_content.py`: плотность ключевого слова + топ-термины
(скрипты/стили вырезаются, чтобы не раздували счётчик слов). Чистый Python stdlib.

**Команды** (в `commands/`): seo-content, seo-keywords, seo-headings, seo-images.

**Не применять:** для тех-аудита — `seo-audit`; для разметки — `seo-schema`;
для краулинга/структуры/конкурентов — `seo-crawl`.
