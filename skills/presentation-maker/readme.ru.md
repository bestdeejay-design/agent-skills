# presentation-maker (RU) — DEPRECATED

> Русское описание скилла. Сам скилл (`SKILL.md`, `skill.json`) — на английском.

**Статус: устарел (роутер).** Скилл разбит на три фокусных. Загружай их напрямую:

- структура/аутлайн/лейауты → `deck-outline`
- HTML-слайды 16:9 + верификация → `deck-html`
- сборка .pptx → `deck-pptx`

Старые скрипты и шаблоны перенесены в новые скиллы. Роутер держится один цикл
релиза для обратной совместимости, затем удаляется.
