## Дизайн-система (обязательно к соблюдению)

Шаблон `templates/slides.html` уже содержит полную дизайн-систему: токены пространства/типографики, хелпер-классы и эстетические режимы (`mood`). Палитра приходит в `:root`-переменные из темы, при этом **дизайн-токены шаблона сохраняются** (сборщик переопределяет только палитровые переменные). Соблюдай систему, а не подгоняй стили «под каждую презентацию».

### 5 принципов (критично)

1. **≤2 шрифтовых семейства, ≤3 начертания.** `--font` (основной, текст/UI) и опционально `--font-display` (заголовки/акценты). Не заводи новые семейства ради пары слайдов.
2. **≤4 акцентных цвета + 1 нейтральный фон.** Палитра = 1 primary, до 2–3 акцентов (светлый/тёмный), нейтрали (`background`, `card`, `stroke`, `text`, `muted`). Больше — шум.
3. **Одна цель на слайд, один фокус-объект.** Не смешивай метрику, таблицу и график без нужды. Взгляд зрителя должен упираться в якорь (заголовок/ключевая цифра), а не блуждать.
4. **Контраст текста WCAG ≥ 4.5:1 (текст) и ≥ 3:1 (крупный/акценты).** Светлый текст на тёмном фоне и наоборот. Проверяй глазами на финальном скриншоте.
5. **Thumbnail-тест и ритм.** Слайд должен читаться с расстояния вытянутой руки и в миниатюре: крупная иерархия, воздух, единые отступы.

### 5.2 Токены (в шаблоне, используй вместо хардкода)

- **Spacing** (4px-база): `--s-1:4px … --s-9:96px` — для отступов, gap, padding.
- **Type scale** (16:9, масштабируется по размеру слайда): `--t-display`, `--t-h1`, `--t-h2`, `--t-h3`, `--t-body`, `--t-meta`, `--t-caption`.
- **Радиусы**: `--radius`, `--radius-sm`, `--radius-lg`, `--radius-full`.
- **Тени**: `--shadow`, `--shadow-hover`, `--shadow-soft`.
- **Шрифты**: `--font`, `--font-display`, `--font-mono`.
- **Контраст**: переменные `--contrast-*` (прозрачность текста по иерархии).

### 5.3 Хелперы (в шаблоне, используй в лейаутах)

- `.eyebrow` / `.eyebrow--accent` — маленький надзаголовок-рубрикатор над `h1/h2`.
- `.kicker` — подзаголовок-лид после заголовка.
- `.mono` — моноширинный текст (числа, коды, метаданные).
- `.hairline` — волосяная линия-разделитель.
- `.duotone` — двухцветный градиентный заголовок (color-mix primary+bg).
- `.index-num` — крупный номер индекса/счётчик секции.

### 5.4 Эстетические режимы (`mood`) на `.deck`

Mood можно задать в `deck.json` (`"mood": ...`) или уже вшит в темы (см. `templates/themes/*.json`). Он переопределяет радиусы/тени/шрифтовую стилистику, не трогая основной палитры.

| mood | Характер | Когда использовать |
|---|---|---|
| `swiss` | минимализм, строгая сетка, волосяные линии, display-акценты | бизнес, стратегия, аналитика, «чисто и строго» |
| `editorial` | журнальная типографика, serif-display заголовки, дуо-градиенты | бренды, контент, креатив, премиум-сторителлинг |
| `flat` | ровные карточки, крупные радиусы, без теней, бенто | стартапы, продукт, современная лаконичность |
| `glass` | полупрозрачные карточки, blur, glow — Apple-стиль | tech-продукт, keynote-стиль, премиум UI |
| `dark` | тёмный блок, моноширинная индексация, консольная строгость | тех, код, data-анализ, ночной режим |

Правило mood: не смешивай 2+ режима в одной презентации; mood должен согласовываться со смыслом (не ставь светлый мягкий mood для тёмной палитры и наоборот).

### 5.5 Перенос концепции в PPTX (`build_pptx.py`)

HTML-система переносится в `.pptx` 1:1 тем же `deck.json`: все **14 типов** слайдов
рисуются через единый набор элементов (см. SKILL.md → «PPTX design system»).
Холст 1600×900 px (`PX=7620`), контракты: `MARGIN_X=96`, `TITLE_Y=56`,
`TITLE_H=96`, `CONTENT_Y=180`, `BOTTOM_STOP=80`. Шрифт — **только Arial**
(LibreOffice не подменяет его при рендере QA).

Ключевые элементы, перенесённые из концепции:

- **eyebrow** — рубрикатор (аналог `.eyebrow`), обязателен на title/divider/closing;
- **ghost-num** — полупрозрачный номер слайда (аналог `.index-num`);
- **chrome** — лого 30×30 + индикатор `NN / NN` на каждом слайде;
- **decor-ovals** — декоративные овалы alpha 15–22% на тёмных слайдах;
- **тёмный «бутерброд»** — title/divider/closing на `primary`, контент — на `background`;
- **карточки** — rounded rect + тень (blur 10/dist 3/alpha 9%);
- **номер-кружки** — OVAL 36–44 px (process/timeline/toc);
- **маркеры-квадраты** — bullet-маркеры в стиле cards;
- **метрики 64pt / кавычка 120pt / hero-число 110pt** — масштабные акценты.

Чек-лист визуального контроля (по JPEG-рендерам `qa_pptx.py --render`):

1. На каждом слайде есть chrome (лого + `NN / NN`) и ghost-номер — ничего не съехало за холст.
2. Тёмные «бутербродные» слайды (title/divider/closing) содержат decor-овалы и eyebrow.
3. Карточки не обрезают текст: заголовки и описания целиком внутри, без пересечений.
4. Таблицы читаемы: первая колонка выделена (40%), ячейки не обрезаны, контраст AA.
5. Шрифт везде Arial — рендер LibreOffice совпадает с ожидаемым в PowerPoint.
