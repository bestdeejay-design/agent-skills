- [Явная боль] — то, о чём они говорят вслух
- [Скрытая боль] — то, о чём не говорят, но что мешает спать

- [Мечта] — идеальный мир через год

### Что мешает?
- [Внутренние барьеры] — сомнения, ресурсы, компетенции

#### Шаг 1.2: Narrative Strategy

**Не «расскажи историю». А «выбери стратегию доставки».**

| Стратегия | Когда использовать | Формула |
|-----------|-------------------|---------|
| **Sparkline** (Duarte) | Визия, изменение мира | WHAT IS ↔ WHAT COULD BE |
| **Hero's Journey** | Личная история, кейс | Ordinary → Challenge → Transformation → Return |
| **SCQA** (McKinsey) | Бизнес-проблема | Situation → Complication → Question → Answer |
| **Detective** | Исследование, открытие | Clue → Clue → Clue → REVELATION |
| **Skeptic-to-Believer** | Убеждение скептиков | Objection → Evidence → Reframe → Conversion |
| **Myth-Busting** | Разрушение мифов | Everyone thinks X → But actually Y → Because Z |
| **One Big Idea** | Ключевое сообщение | Statement → Why → How → Proof → CTA |

**Как выбрать**: Задай себе вопрос: «Что должна почувствовать аудитория в конце?»

- Восхищение → Sparkline
- Уважение → Hero's Journey
- Понимание → SCQA
- Удивление → Detective
- Убеждённость → Skeptic-to-Beliber
- Освобождение → Myth-Busting
- Решимость → One Big Idea

#### Шаг 1.3: The Hook

**Первые 30 секунд решают всё.**

```
Формула хука:

[Шокирующий факт/вопрос] + [Почему это важно ДЛЯ НИХ] + [Что будет, если мы это изменим]
```

**Примеры мироизменяющих хуков:**

- «Каждый год умирает 5 миллионов детей от болезней, которые мы умеем лечить. Не потому что нет лекарств. А потому что они не доходят.»
- «Вы тратите 40% времени на работу, которая не приближает вас к цели. Не потому что вы ленивые. А потому что система так устроена.»
- «Через 10 лет 40% рабочих мест исчезнут. Не потому что роботы. А потому что мы не научимся работать с роботами.»

#### Шаг 1.4: Time-Budget Architecture

**Каждый слайд = время жизни.**

```
Время на слайд:

[Слайд] → [Время] → [Цель] → [Ключевая мысль] → [Доказательство]
```

**Правила time-budgeting:**

| Тип слайда | Время | Причина |
|------------|-------|---------|
| Хук / открытие | 60-90 сек | Нужно зацепить, не объяснять |
| Проблема | 45-60 сек | Достаточно для боли, не для анализа |
| Решение | 60-90 сек | Нужно объяснить «как», не «что» |
| Доказательство | 30-45 сек | Данные говорят сами за себя |
| CTA | 45-60 сек | Чёткий призыв к действию |

**Итого**: 15-минутная презентация = 10-12 слайдов. Не 30.

#### Шаг 1.5: Action Titles

**Не «Результаты». А «Мы увеличили выручку на 340% за 6 месяцев».**

```
Правило Action Title:

[Глагол] + [Объект] + [Результат] + [Контекст]

ПЛОХО:
- «Результаты исследования»
- «Наш подход»
- «Преимущества решения»

ХОРОШО:
- «Мы нашли 3 узких места, которые крадут 40% вашего времени»
- «Наш подход сократил время вывода продукта с 12 до 3 месяцев»
- «Эти 5 компаний увеличили выручку на 200% за первый год»
```
