# seo-crawl (RU)

> Русское описание скилла. Сам скилл (`SKILL.md`, `skill.json`) — на английском.

**Назначение:** слой краулинга и видимости — достучатся ли поисковики до сайта:
robots.txt, noindex, canonical, цепочки редиректов, sitemap.xml; внутренняя
перелинковка, глубина кликов, осиротевшие страницы, иерархия URL, хлебные крошки;
сравнение с конкурентами (разрывы, пересечения ключей, контент-гэпы).

**Команды** (в `commands/`): seo-crawl, seo-structure, seo-compare (URL-only).
Режимы: URL и File.

**Не применять:** для тех-аудита — `seo-audit`; для разметки — `seo-schema`;
для контента — `seo-content`.
