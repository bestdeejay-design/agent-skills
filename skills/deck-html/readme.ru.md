# deck-html (RU)

> Русское описание скилла. Сам скилл (`SKILL.md`, `skill.json`) — на английском.

**Назначение:** сборка автономных HTML-слайдов (16:9) из JSON-спеки `deck-outline`.
Самодостаточный файл: весь CSS внутри, ноль внешних ссылок, стрелки/клавиатура/touch.

**Пайплайн:** выбор темы (general/modern/executive/momentum/swift/standard) →
палитра (ключи `primary/background/card/...`, одинаковая для html и pptx) →
`build_html.py` копирует шаблон, подставляет контент и палитру в `:root`.

**Обязательный гейт перед сдачей:**
1. `verify_slides.py` (Playwright + Chromium): переполнения, текст вне карточек,
   обрезанный текст, навигация, число слайдов. Exit 0 = PASS, 1 = FAIL.
2. Визуальный контроль глазами (воздух, крупные метрики, единая палитра).
3. Продакт-дизайн-ревью по `references/product-designer.md`.

**Не применять:** для структуры — `deck-outline`; для .pptx — `deck-pptx`.
