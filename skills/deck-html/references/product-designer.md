## Продакт-дизайнер — расширенные требования к презентации

Модуль добавляет «продуктовый взгляд» на слайды поверх дизайн-системы. Это не эстетическая пожелательность, а **проверяемые требования**: итоговая дека проходит сводный чек-лист «Продакт-дизайнер» (внизу) до сдачи. Разделы: **нарратив/ИА**, **визуализация данных**, **доступность и типографика**, **премиум-ощущение**.

### A. Нарратив и информационная архитектура

**Дуги (по характеру контента):**
| Дугa | Когда | Схема |
|---|---|---|
| Problem→Solution→Proof→CTA | аудитория ещё не знакома с проблемой | боль → решение → доказательства → один призыв |
| Sparkline (Duarte) | нужно убедить / большая идея | чередование «что есть» ↔ «что могло бы быть» **на протяжении** презентации |
| STAR | доказать компетенцию кейсом | Situation→Task→Action→Result (один слайд = один кейс) |
| S.T.A.R. Moment | есть одна шокирующая цифра/поворот | один запоминающийся момент на всю деку |

**IA на слайде:**
- **Одна идея на слайд** — слайд отвечает на один вопрос; две независимые мысли → два слайда.
- **Заголовок = вывод, а не тема** (assertion headline): полное предложение с глаголом и утверждением («Рост выручки ускорился до 40% в Q3» вместо «Выручка»).
- **Пирамида (Minto)**: тезис сверху, под ним ≤3 опоры, каждая подкреплена фактами; опоры — MECE.
- **Прогрессивное раскрытие**: детали/данные не вываливаем на один слайд — сложное на отдельные слайды/приложение.

**Сторибординг:** setup→payoff (ранние детали «выстреливают» позже), foreshadowing (намёк на будущий вывод), правило трёх, сквозная линия (каждый слайд продвигает главную идею; лишний — удалить), логические переходы между слайдами.

**Консалтинг vs питч vs кинот:** консалтинг — пирамида + SCQA, плотные данные, assertion-заголовки, аудитория читает сама; питч — проблема/решение/рынок/тракция/команда/CTA, 10 минут, метрики; кинот — sparkline, эмоциональная дуга, минимум текста.

**Анти-паттерны:** slide-ument (слайд = документ), много буллетов, орфан-слайды, нет переходов, нет сквозной линии, заголовок-тема вместо вывода.

### 2. Визуализация данных

**Выбор типа (сначала сформулируй единственное сообщение слайда, потом тип):**
| Форма данных | Сообщение | Тип |
|---|---|---|
| Тренд во времени | «как меняется» | линия (не более 3–5 серий) |
| Ранжирование | «кто больше» | бары, отсортированные по убыванию |
| Доли до 100% | «как делится целое» | донут/пирог **только** при ≤5 долях; иначе stacked bar |
| Сравнение значений | «разница» | столбцы (или таблица) |
| Много точных значений / поиск строк | «посмотри на данные» | таблица |
| Одно число + контекст | «вот результат» | metric card (не график) |

**Чистые графики:** минимум сетки, прямые подписи вместо легенды, сортировка баров, максимум 2 знака после запятой (лучше 0–1), ось Y столбцов с 0, без 3D, единые шкалы при сравнении, без двойной оси.

**Metric card:** округли до 1–2 значащих цифр («12,4 млн» не «12 431 287»); префикс/суффикс единиц; дельта vs цель (▲/▼ +12% или 68% из 100%); контекстное сравнение; крупное число + мелкая подпись.

**Таблицы:** ≤5–7 столбцов и ≤8–12 строк; числа — вправо, текст — влево; зебра/тонкие линии; **подсвети ответ** (ключевая строка/ячейка выделена); первый столбец — человекочитаемый идентификатор.

**Честность (Tufte):** data-ink ratio (макс «чернил» на данные), сигнал vs шум, не обрезай ось столбцов, не подбирай базовую линию, подписывай единицы.

### 3. Доступность и типографика (WCAG)

- **Контраст (WCAG 2.1/2.2 AA):** обычный текст ≥4.5:1, крупный (≥18pt/24px или 14pt bold) ≥3:1. Для слайдов цель — AAA-запас (7:1 / 4.5:1): проектор «съедает» контраст. **Не округляй** — 4.49:1 == фейл.
- **Авто-палитра:** текст задаётся по фактическому фону (тёмный фон → near-white текст, светлый фон → near-black), контраст считается программно, а не «по красоте».
- **Не только цвет (1.4.1):** серии графика/статусы различаются не только цветом — есть паттерн/иконка/подпись.
- **Не-текст (1.4.11):** линии, сегменты, границы, состояния ≥3:1 против соседних цветов.
- **Типoграфика проекции (1080p):** заголовок ≥36–44px, тело ≥24–28px, подписи ≥18–20px; крупный x-height; длина строки 40–70 символов; межстрочный 1.3–1.5; тело не капсом.
- **Текст на «шумном» фоне:** непрозрачная плашка или скрим над фото/градиентом; обводка — только дополнение.
- **Читаемость:** правило 50/25/10 (≤50 слов — сложный, ≤25 — обычный, ≤10 — ключевой); без переносов и обрезки текста в контейнерах.

### 4. Премиум-ощущение (планка качества)

**Рычаги «дорого»:** пробел как роскошь (на слайде контент <60% площади), единые поля и сетка, сдержанная палитра (60-30-10: 60% фон, 30% текст/карточки, ≤10% акцент), типографическая иерархия из 3 уровней, один доминирующий элемент на слайд, единая иконография (одна толщина штриха), сдержанное движение.

**Сигналы «дёшево»:** всё по центру, клип-арт/стоковый вид, **эмодзи как иконки**, радужная палитра, чрезмерные тени, многословные слайды, несогласованное выравнивание, дефолтный стиль PPT.

**Дизайн-контракт (держать на каждом слайде):** одна позиция заголовка, один радиус карточек, одна толщина штриха иконок, один источник всех чисел, одна палитра/отступы/тень/переходы. Нарушение хотя бы на одном слайде — «собрано из кусков».

### Сводный чек-лист «Продакт-дизайнер» (пройти перед сдачей)

**Нарратив / ИА**
1. Каждый заголовок — assertion headline (вывод, а не тема).
2. Одна идея на слайд; нет двух несвязанных утверждений.
3. Слайд логически вытекает из предыдущего; все продвигают сквозную линию (нет орфанов).
4. Тело подтверждает заголовок; ≤3–5 буллетов, каждый — короткая фраза.
5. Есть сквозная линия (по заголовкам всех слайдов читается история) и CTA в конце.
6. Есть контраст «что есть / что могло бы быть» (для убедительных); есть один S.T.A.R. момент.

**Данные**
7. Каждый график/таблица/карточка имеют подпись-вывод (что видеть).
8. Ранжирование → бары по убыванию; столбцы → ось Y с 0; линия → ≤5 серий, без двойной оси.
9. Пирог/донут → только доли ≤100%, ≤5 долей, без 3D, подписи напрямую.
10. Числа ≤2 знака после запятой, с единицами; metric card округлена до 1–2 значащих цифр, есть дельта.
11. Таблица ≤7 столбцов / ≤12 строк; числа вправо, текст влево; ключевая строка/ячейка подсвечена; единицы подписаны.

**Доступность**
12. Контраст каждого текста ≥4.5:1 (крупный ≥3:1); не-текст ≥3:1; без грубой округляемой ошибки.
13. Тело ≥24px (1080p), длина строки 40–70, межстрочный 1.3–1.5; нет капса в теле.
14. Серии/статусы различаются не только цветом; текст над фото/градиентом — с подложкой.

**Премиум**
15. ≤1 стиль тени на всю деку; единый радиус карточек; заголовки на одной базовой линии.
16. Ни одного элемента ближе 40px к краю слайда; элементы на сетке (шаг ≥4px).
17. Палитра ≤3 ролей, акцент ≤10%; контент на слайде <60% площади; нет эмодзи-иконок.
