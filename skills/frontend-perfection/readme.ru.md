# frontend-perfection (RU)

> Русское описание скилла. Сам скилл (`SKILL.md`, `skill.json`) — на английском.

**Назначение:** аудит и доведение фронтенда (статический HTML/CSS/JS или собранный
SPA) до измеримого совершенства. Скилл построен на **стабильных API**: реальный Chrome
через `chrome-launcher` + Lighthouse Node API (без внутренностей Playwright), точные
расчёты (контраст по вычисленной яркости, а не «на глаз»), отчёт before/after,
привязанный к audit-id.

**Что умеет:**
- **`scripts/audit.js`** — Lighthouse ≥13, mobile+desktop, порог по умолчанию 100,
  exit 0/1/2, компактный JSON-отчёт с провалившимися аудитами.
- **`scripts/meta_audit.py`** — офлайн-статический аудит (чистый Python stdlib):
  SEO-мета слой, WCAG-контраст, порядок заголовков, **a11y-проверки по правилам
  axe-core** (alt у картинок, доступные имена у кнопок/ссылок, label у форм,
  валидность ARIA-атрибутов, уникальность landmark'ов), дизайн-токены (ноль raw-hex
  вне блока токенов), scroll-padding под фиксированную шапку, адаптивность.
- **OG-image** — безопасная для кадрирования картинка 1200×630 (~640px центральная
  зона), смена URL вместо перезаписи (сброс кешей соцсетей).

**Когда применять:** просят «сделай вёрстку идеальной», «подними перформанс»,
«100/100/100/100», «проверь страницу», «audit the page»; нужен OG-image или SEO-мета;
жалуются на контраст, отсутствующие теги, дубли цветов в raw-hex.

**Формат работы:** найти проект → поднять локально (`python3 -m http.server 8377`) →
прогнать `audit.js` (mobile+desktop) и `meta_audit.py` → чинить по audit-id →
повторный аудит до зелёного → отчёт before/after.

**Русские триггеры:** «проверь вёрстку», «довести фронтенд до идеала», «контраст
цветов», «дизайн-токены», «SEO-мета слой» — раньше были триггерами скилла; после
EN-миграции матчинг идёт по английским триггерам и fuzzy-скорингу описаний.
