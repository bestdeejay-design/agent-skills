# github-repo-hygiene (RU) — DEPRECATED

> Русское описание скилла. Сам скилл (`SKILL.md`, `skill.json`) — на английском.

**Статус: устарел (роутер).** Скилл разбит на четыре фокусных. Не выполняй воркфлоу
из этого файла — загружай подходящий скилл напрямую:

- README (EN + зеркало) + анимированный SVG header/footer → `repo-readme-assets`
- LICENSE / CODE_OF_CONDUCT / CONTRIBUTING / SECURITY / SUPPORT / шаблоны → `repo-community-files`
- description / topics / GitHub Pages / community health / 16-пунктовый чек-лист → `repo-metadata-health`
- social preview (og:image) PNG 1280×640 → `repo-social-preview`

Старые скрипты и references перенесены в новые скиллы. Роутер держится один цикл
релиза для обратной совместимости (глобальное правило `AGENTS.md` может ссылаться на
`github-repo-hygiene`), затем удаляется.
