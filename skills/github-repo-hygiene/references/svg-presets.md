# Пресеты оформления header/footer

> Четыре пресета для `scripts/generate_assets.py --preset <name>`.
> Все пресеты генерируют самодостаточные локальные SVG (ноль внешних сервисов)
> и проходят `scripts/validate_svg.py` (для minimal/monochrome допустимо
> предупреждение «no SMIL animation» — статичность намеренная).

## default

То, что было каноном: переливающийся градиент `COLD→WARM`, морфинг волн
(4 кадра, `Q`+`T`), рассинхрон 30%, блик-проход раз в 16s, эффект «фон
наползает» через маску, fade-появление текста, twinkling в footer.

```bash
python3 scripts/generate_assets.py --name "X" --desc "Y" --user "u" \
  --cold "#0ABAB5" --warm "#F64A8A" --preset default
```

## minimal

Однотонный градиент без анимации — для репозиториев, где движение лишнее
(документация, книги, стабильные тулы). SMIL полностью удалён: статичный
градиент, статичные волны, статичная маска. GitHub рендерит как обычную картинку.

```bash
python3 scripts/generate_assets.py --name "X" --desc "Y" --user "u" \
  --cold "#0ABAB5" --warm "#F64A8A" --preset minimal
```

## dark-first

Обычный анимированный вид, но под градиентом — тёмная подложка `#0D1117`
(оригинальный фон GitHub dark) с полупрозрачным градиентом поверх: баннер
выглядит глубоко-тёмным на светлой теме и не слепит в тёмной. Текст — белый
по умолчанию.

```bash
python3 scripts/generate_assets.py --name "X" --desc "Y" --user "u" \
  --cold "#0ABAB5" --warm "#F64A8A" --preset dark-first
```

## monochrome

Чёрно-белая статичная версия для документации/печати. Палитра принудительно
`#2A2A2E` → `#9A9AA2` (аргументы `--cold/--warm` игнорируются). Статичен, как
minimal.

```bash
python3 scripts/generate_assets.py --name "X" --desc "Y" --user "u" \
  --cold "#0ABAB5" --warm "#F64A8A" --preset monochrome
```

## Правила, общие для всех пресетов

- Маска с белым `<rect>` на весь холст + чёрная волна-вырез — обязательна
  всегда (эффект «фон наползает» работает и в статике).
- В минимале/монохроме не остаётся SMIL — удаляются только `<animate>`
  и блик-слой; структура (`defs`, `mask`, волны, текст с дубль-тенью) сохраняется.
- Футер в любом пресете — зеркало header (инверсия градиента, дыра сверху).
- После генерации всегда прогонять проверку:

```bash
python3 scripts/validate_svg.py assets/
```
