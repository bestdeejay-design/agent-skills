# seo-audit (RU)

> Русское описание скилла. Сам скилл (`SKILL.md`, `skill.json`) — на английском.

**Назначение:** техническое SEO-здоровье сайта: полный тех-аудит (meta, заголовки,
alt, битые ссылки, sitemap, robots.txt, canonical), Core Web Vitals (LCP/CLS/INP),
взвешенный отчёт (7 измерений), автофиксы с приоритизацией P1–P5 и правилом
diff-before-apply.

**Команды** (в `commands/`): seo-audit, seo-speed, seo-report, seo-fix. Режимы:
URL (внешний сайт) и File (локальный проект).

**Не применять:** для разметки (schema/meta) — `seo-schema`; для контента/ключей/
заголовков/картинок — `seo-content`; для краулинга/структуры/конкурентов — `seo-crawl`.
