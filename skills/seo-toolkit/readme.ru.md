# seo-toolkit (RU) — DEPRECATED

> Русское описание скилла. Сам скилл (`SKILL.md`, `skill.json`) — на английском.

**Статус: устарел (роутер).** 13 команд разбиты на четыре фокусных скилла:

- тех-аудит / Core Web Vitals / отчёт / автофиксы → `seo-audit`
- JSON-LD / meta / OG / Twitter → `seo-schema`
- контент / ключи / заголовки / картинки → `seo-content`
- краулинг / перелинковка / структура / конкуренты → `seo-crawl`

Старые команды и скрипты перенесены в новые скиллы. Роутер держится один цикл
релиза, затем удаляется.
