# docs-system (RU) — мета-гайд и роутер

> Русское описание скилла. Сам скилл (`SKILL.md`, `skill.json`) — на английском.

**Статус: мета-гайд + роутер.** Две ветки живут в фокусных скиллах:
- **`docs-product`** — «зачем» и «что»: VISION → PRD → ROADMAP → FEATURES.
- **`docs-project`** — «как»: README/ENTRY/ARCHITECTURE/ADR/контракты/тесты + карта REFERENCE.

Этот скилл — для общей картины: какие документы писать, в каком порядке
(`references/order.md`), насколько глубоко (`references/levels.md`, L1/L2/L3)
и что значит «полный набор» (`references/completeness.md`).

**Когда применять:** задача про систему документации целиком; нужно применить
фазы/уровни/чек-лист полноты. Если задача чётко продуктовая или инженерная —
загружай ветку напрямую.
