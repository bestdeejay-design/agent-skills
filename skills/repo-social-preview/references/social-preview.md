# Social preview (og:image) — как создать

GitHub **сам** генерирует превью репозитория, но кастомное социальное превью
(картинка при шаринге ссылки на репо и в OG-тегах Pages-сайта) ставится только
через **Settings → Social preview → Edit → Upload** — публичного REST/CLI API для
заливки **нет**. Скрипт `scripts/render_social_preview.py` лишь **рендерит**
свёрстанную hero-секцию в PNG, который ты потом заливаешь вручную.

## Спецификация файла

- Формат: **PNG / JPG / GIF**, размер **< 1 MB**.
- Минимальное разрешение: **≥ 640×320**; рекомендовано **1280×640**.
- Расположение в репо: корень / `docs/` / default-ветка (для raw-ссылки) и/или
  в `assets/` (для встраивания в README).
- Сплошной фон рекомендуется (прозрачность поддерживается, но может
  некрасиво смотреться на тёмных карточках соцсетей).
- Для Pages-сайта укажи `og:image` в `<head>`:

  ```html
  <meta property="og:image" content="https://<user>.github.io/<repo>/og-2026-08-11.png">
  <meta name="twitter:image" content="https://<user>.github.io/<repo>/og-2026-08-11.png">
  ```

## Workflow (v2 — HTML hero, без генерации SVG)

1. **Источник**: если у проекта есть сайт с hero-секцией — берём оттуда заголовок,
   подзаголовок, палитру и шрифты и **перевёрстываем чистую hero** (без хедера,
   навигации, футера, бейджей). Не скриншотим сайт. Свои SVG не рисуем вообще —
   только HTML/CSS; из ассетов сайта можно ссылаться на существующий логотип и шрифты.
2. **Вёрстка**: standalone `hero.html` под фиксированный viewport 1280×640;
   `padding: 40pt` со всех сторон (crop-safe зона GitHub — важный текст и лого
   не граничат с краями); сплошной фон или жёсткие цветовые стопы; контраст ≥ WCAG AA.
   Вёрстку вести по правилам скилла `frontend` (типографика, токены бренда).
3. **Рендер**: headless Chrome делает пиксель-точный снимок реальной веб-вёрстки:

   ```bash
   python3 scripts/render_social_preview.py hero.html --out og.png
   # опционально: --width 1280 --height 640 (по умолчанию)
   ```

   Скрипт сам ищет Chrome/Chromium/Edge/Brave, ждёт загрузки вебшрифтов
   (`--virtual-time-budget=10000`) и печатает размер файла и разрешение PNG.
4. **Проверка**: ровно 1280×640, < 1 MB, ничего не обрезано по краям, текст
   читается в миниатюре. Если что-то не так — правим HTML и рендерим заново.
5. **Загрузка**: вручную через Settings → Social preview → Edit → Upload.

## Чек-лист

- [ ] `hero.html`: только hero-секция, `padding: 40pt`, без хедера/футера/бейджей.
- [ ] Никаких самодельных SVG; шрифты и палитра — от сайта/бренда.
- [ ] PNG 1280×640, < 1 MB, в репо.
- [ ] `og:image` прописан в `<head>` Pages-сайта.
- [ ] Картинка **вручную** загружена в Settings → Social preview.
