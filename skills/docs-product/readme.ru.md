# docs-product (RU)

> Русское описание скилла. Сам скилл (`SKILL.md`, `skill.json`) — на английском.

**Назначение:** продуктовая ветка документации — «зачем» и «что»:
`VISION.md`, `PRD.md`, `ROADMAP.md`, `FEATURES.md`. Пишется от идеи вперёд,
до инженерной документации. Золотая цепочка: **VISION → PRD → ROADMAP → FEATURES**.

**Когда применять:** просят «продуктовую документацию», «vision», «prd»,
«роадмап», «требования к продукту».

**Не применять:** для инженерной ветки (архитектура/ADR/тесты/карта) —
`docs-project`; для мета-гайда (фазы, уровни L1/L2/L3, чек-лист полноты) —
`docs-system`.

**Шаблоны:** `templates/VISION.tmpl`, `PRD.tmpl`, `ROADMAP.tmpl`, `FEATURES.tmpl`.
Полный каталог и чек-лист — в `references/product-docs.md`.
