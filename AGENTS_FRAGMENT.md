# Фрагмент для AGENTS.md — автозахват фидбека по скиллам

Скопируй секцию ниже в свой `~/.config/opencode/AGENTS.md` (или системный промпт
агента), чтобы петля улучшения скиллов работала **автоматически**, без явных
напоминаний. Это делает скиллы самообучающимися в твоём окружении.

---

## Автозахват фидбека по скиллам (skill-feedback)

При использовании любого скилла: если скилл не сработал на релевантный запрос
(near-miss), сработал не туда (wrong trigger) или пользователь вручную поправил
его результат — сам вызови скилл `skill-feedback` (add), не спрашивая подтверждения.
Это питает локальную петлю улучшения скиллов (Layer C в `docs/SKILL_QUALITY_GATE.md`).

- Фидбек пишется в `feedback/<skill>/YYYY-MM-DD.jsonl` репозитория со скиллами.
- Типы записи: `near_miss_trigger`, `wrong_trigger`, `output_issue`,
  `manual_correction`, `description_gap`.
- Когда фидбека накопилось достаточно — улучшай свои скиллы локально командой
  `python3 skills/skill-forge/scripts/forge_from_feedback.py` (или `--dry-run`
  для предпросмотра). Коммит локальный, без пуша — ты контролируешь результат.

---

Так каждый, кто пользуется набором скиллов, растит свои скиллы сам, на своём
клоне/форке, без центрального сервиса.
